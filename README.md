# HSEQ Gate

Entrenamiento inmersivo de seguridad industrial en realidad virtual para Meta Quest 3S — Voltac Systems S.A.S.

La persona entra a un entorno industrial a escala real y ejecuta, paso a paso, procedimientos críticos de
seguridad: bloqueo y etiquetado de energías (LOTO), trabajo en alturas, ingreso a espacios confinados y
más. El sistema guía, corrige, detecta errores críticos (con su consecuencia simulada) y evalúa. Así se
hace inducción y reentrenamiento **sin exponer a nadie en campo**.
